Terminal guide

nthn

A local Linux terminal for Android. Commands run in this app's own environment.

Sessions

Swipe from the left edge to see sessions, open Settings, start a new session, or show the keyboard. Long press a session to rename or close it.

Keys and text

Use the extra keys row for Esc, Tab, Ctrl, and navigation. Long press in the terminal to select or paste text. Press Ctrl+C to interrupt a running command.

Packages

This app uses the /data/data/com.nthn/files/usr prefix. Packages built for a different app prefix may fail. Install packages built for this prefix, or use a Linux root filesystem inside proot.

Source and support

nthn source and build notes

nthn is based on the open source Termux terminal implementation. See the repository for source and license notices.
