# NTHN chat UI preview

This is the web-first design prototype for the future `com.nthn` chat interface. It is intentionally limited to the conversation and AI provider sidebar.

Open `index.html` directly in a browser, or serve this folder locally:

```sh
python -m http.server 4173 --directory apps/nthn/ui-preview
```

Then visit `http://127.0.0.1:4173`.

The provider form is visual-only in this preview. It does not store or send API keys.
