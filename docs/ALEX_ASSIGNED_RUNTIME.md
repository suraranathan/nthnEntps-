# Alex assigned runtime

Alex uses the saved agent `01` primary route when it has current verified text and system-instruction evidence. The server reads the existing encrypted provider connection and sends chat through the Phase 2 protected transport. The original identity, personality, explicit memory, relevant conversation history, office facts, project document and Sophia queue are assembled by `AlexRuntime` for every request. The model cannot execute tools or deliver to Sophia; the existing user-approved Sophia queue remains available.

Open **AI Providers** to select the primary and ordered fallback routes. Each route must be compatible when saved and is checked again before inference or a switch. Credentials remain in the server vault. Alex's chat shows the serving model and retains the full transcript across switches.

Only three consecutive successful responses of at least 12 seconds, an observed positive OpenRouter key limit with at most 10% remaining, or an HTTP 429 rate-limit response can trigger a switch. The key allowance is read through the protected authenticated `/key` endpoint; missing allowance data does not imply a limit. A 429 request fails honestly, and any switch is prepared before the next request. Only saved ordered fallbacks are eligible. The adapter refreshes stale discovery and explicitly verifies a saved fallback's required capabilities if needed before switching. Verification may incur provider charges. It does not switch for model age, price, capability rankings or generic failures. Each switch records an event and appears in Alex's chat with its reason.

If no saved verified fallback exists, Alex reports the slow or limit condition and does not claim successful inference. Saving a compatible fallback lets the next request reassess it. Automatic switching is intentionally narrower than a general model manager; Nexus is not implemented.

On 2026-10-30, a protected real OpenRouter dashboard chat request succeeded through `aion-labs/aion-2.0`, the saved primary. Alex replied as employee 01 and the dashboard API reported `online`. No real switch occurred because the saved assignment has one candidate. Regression tests use isolated simulated providers for slow, rate-limit and fallback paths; they are not evidence of a live fallback. The existing Sophia adapter is still unavailable, and no executable model tools were added.
