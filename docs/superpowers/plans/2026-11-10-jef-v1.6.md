# Jef V1.6 Implementation Plan

> **For agentic workers:** Implement the tasks in order with focused tests and verification.

**Goal:** Ship one Jef update with cross-chat memory, useful lessons, and better mobile coding workflow.

**Architecture:** A local memory store lives beside the existing conversation store. The agent retrieves scoped memories before model calls and records explicit corrections and verified outcomes. The mobile CLI and Android bridge expose memory, history, stop, and reviewed edits to the WebView.

**Tech Stack:** TypeScript/Node, Java Android bridge, HTML/CSS/JS chat asset, node:test.

**Spec:** `docs/superpowers/specs/2026-11-10-jef-v1.6-design.md`

- [x] Integrate selective retrieval and conservative learning into Jef's agent loop.
- [x] Add tested reviewed multi-file edit proposals and exact approval previews.
- [x] Expose history, stop, memory management, and checkpoints through CLI and Android bridge.

- [x] Improve search and model preference without weakening confinement or approvals.

- [x] Increment version, document behavior, run focused and full verification, review diff.

## Review Focus

- A memory mentioning a secret must not be saved automatically.
- A memory from one project must not appear in another project's context.
- A changed source file must make a linked memory stale.
- Denied or expired edits must never execute.
- Stop must terminate the running request without corrupting saved chat state.
