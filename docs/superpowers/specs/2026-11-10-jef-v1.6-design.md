# Jef V1.6: memory and working tools

## Intent

One app update gives Jef useful memory across chats and improves its ability to finish coding tasks efficiently. Jef remains a coding agent with explicit approval for file writes and commands.

## Memory

- Keep personal memories across projects and project memories within one selected workspace.
- Store short facts, preferences, decisions, goals, checkpoints, and lessons with source, date, and editable status. Never automatically store secrets or raw tool output.
- Learn from explicit user corrections and verified test outcomes; do not treat one failed command as a general lesson without a known cause.
- Retrieve only relevant memories into model context. Mark project facts stale when their cited file changes. Let the user add, edit, pin, and delete memories.
- Keep data in app-private local storage. Jev is optional future routing support, not a requirement for memory.

## Working tools

- Show the exact proposed file changes before approval, and support a reviewed set of file changes as one action.
- Expose stop, chat history, and clear task checkpoints in the mobile chat.
- Improve project search and provide a fast / balanced / low cost model preference with visible provider and model information where available.
- Preserve the existing workspace confinement, command allowlist, and approval checks.

## Delivery

Increment `apps/nthn/VERSION` to `1.6`, update user documentation, and verify TypeScript tests, type checks, Android contract tests, and APK build workflow as far as the local environment supports. Release publishing requires a separate explicit request.
